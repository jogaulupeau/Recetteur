# Recetteur

App Home Assistant : vos recettes, le menu de la semaine, la liste de courses
(avec envoi vers une liste « todo » de Home Assistant) et la recette pas à pas
avec des quantités qui s'ajustent au nombre de personnes.

Interface intégrée à la barre latérale (ingress). Données dans `/data`, donc
conservées d'une mise à jour à l'autre et incluses dans les sauvegardes.

Voir [DOCS.md](DOCS.md) pour l'installation et l'utilisation.
